# ChatGPT 5.5 Codex 使用指南 - 内容笔记

---

## 核心观点

1. **Codex 是目前最优的 AI 编程工具**：比 Claude Code 更好用，且包含在 ChatGPT 免费层级中；$20/月的套餐性价比极高（因 Anthropic 已将 Claude Code 从 $20 层级移除）

2. **多智能体并行工作流**：一个主体 agent 构建应用，一个 marketing agent 生成宣传视频，一个 research agent 自动浏览研究股票信息——如同指挥官调度多个"员工"同时工作

3. **GPT 5.5 足够聪明**：大多数任务用 Medium 模式即可，无需开最高智能，节省用量同时保证质量

## 重要案例

1. **实际构建的应用**：完整股票投资追踪应用，含前端 UI、Convex 数据库存储、实时股价查询、投资组合管理

2. **Live 数据验证**：输入 Google → $349.57，Nvidia → $214 等真实数据，证明 API 集成成功

3. **自动化生成的营销视频**：Remotion skill 自动用真实 UI 截图生成了 40 秒的宣传视频，"之前可能花费数万美元和数天工作"

4. **暗色模式一键实现**：通过标注按钮直接编辑，成功添加深色模式切换

5. **长期使用信心**：作者表示 OpenAI 模型不会越更新越笨（对比 Anthropic），且用量限制慷慨、频繁重置

## 术语解释

- **多智能体系统（Multi-Agent System）**：一种 AI 工作模式，多个 AI agent 并行工作，分别负责不同任务（如开发、研究、营销），由主 agent 统一调度指挥。

- **Reverse Prompting（反向提示）**：一种使用技巧，主动暂停让 AI 询问用户建议下一步做什么，从而利用超级智能辅助决策而非被动接受建议。

- **Annotation 标注编辑**：一种可视化编辑功能，在内置浏览器中直接圈选区域并发送指令，AI 会理解选中的 UI 元素并进行针对性编辑。

- **Automations 自动化**：设置定期自动运行的任务，如每天自动执行代码审查、股票研究等。

- **Convex 数据库**：一款现代云端数据库，作者推荐用于个人项目，有慷慨的免费额度。

---

## 二创角度

1. **工具选择维度**：价格（免费 + $20 套餐优势）、用量限制稳定性、模型智商保持

2. **开发流程**：UI 设计（AI 图片）→ 数据库搭建（Convex）→ 功能实现 → 自动测试 → 部署

3. **多 agent 工作模式设计**：主体开发 + 辅助研究 + 营销产出，如何分配任务与审批

4. **省成本策略**：Medium 智能层级适合大多数任务，避免过度消耗

5. **实时协作编辑技巧**：Annotation + Reverse Prompting 的组合使用

6. **可迁移技能**：任何应用开发都适用——多任务、自动化、营销素材生成
