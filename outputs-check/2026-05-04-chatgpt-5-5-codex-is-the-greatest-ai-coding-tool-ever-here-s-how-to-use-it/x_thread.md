1. 我用了两个月 ChatGPT Codexl，它比 Claude Code 更好，而且免费就能用。Anthropic 已经把 Claude Code 从 $20 套餐移除了，这时候选 OpenAI 是明智的。

2. 它真正厉害的地方不是写代码，而是一个 agent 写代码，另一个 agent 自动生成营销视频，还有一个 agent 研究股票——三个同时跑，等于你雇了一支数字团队。

3. 今天我让 AI 生成了 App 的 UI 设计图，再基于图片直接构建出了完整界面。设计师+开发者的活，一个人用对话就完成了。

4. 数据库我用的是 Convex，慷慨的免费额度，已经跑了 50 多个项目。实时股票数据也接进去了，Google $349、Nvidia $214，直接从 API 拉过来。

5. 每次构建完它会自动打开浏览器测试，验证代码真的能跑。还有标注编辑功能——直接在界面上圈一个区域说"改成深色模式"，它就改了。

6. 自动化任务也很好用，比如每天自动去研究股票、GitHub 代码审查，完全不需要人盯着。

7. 大多数任务用 Medium 模式就够了，不需要开最高智能，省用量同时质量也不差。

8. 它模拟了一个真实的浏览器环境，能像人一样操作网页——搜索、点击、填表，这比单纯的代码补全强大太多了。

9. 之前生成一个营销视频可能要花几万块和几天时间，现在用 Remotion skill 自动化，40 秒的视频几秒钟就跑出来了。

10. AI 编程工具的选择标准其实很简单：模型够聪明、价格稳定、用量限制不抽风。OpenAI 这三点目前都做到了。
